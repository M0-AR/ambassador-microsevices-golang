06 — Read this before you star it

What is real, and what is a demo.

Trust is a feature. This repository is honest about the line between working code and a scripted product tour.

✓Real in this repository

  • Five Go services with HTTP handlers, MySQL repositories, JWT auth, and Kafka producers and consumers.
  • Stripe Checkout payment sessions wired through environment variables — test mode by default. Each order line records a flat 10% ambassador split.
  • Dockerfiles, Compose files, Kubernetes manifests, OpenAPI contracts, and CI workflows you can build and run.
  • A written beginner guide that explains every concept from first principles.

◦Simulated on this page

  • The dashboard, storefront, orders, and payouts in the demo are a client-side simulation with sample data in localStorage.
  • Tiered commission rates and payout transfers are demo-only: the Go services implement a flat 10% split and no Connect transfers yet.
  • No demo interaction calls a Go service, charges a card, or sends an email.
  • The neural-network scene is a conceptual illustration, not a trained model.
  • The ROI numbers are plain arithmetic — included to make the business model legible, not to promise outcomes.
