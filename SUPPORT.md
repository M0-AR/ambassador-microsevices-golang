# Support

## Questions and ideas

- Open a GitHub Discussion for architecture questions, deployment stories, or ideas.
- Open an issue using the bug or feature template for actionable work.
- Read the [beginner guide](README.md#-beginner-guide--read-this-and-you-are-a-professional) and [FAQ](docs/FAQ.md) first.

## What to include

For a bug report:

- The service name and version or commit.
- Your operating system and Go version.
- The exact command you ran.
- The full error message with secrets removed.
- What you expected to happen.
